# Browsium 🌐💻

> Um navegador web leve, moderno e nostálgico desenvolvido para Windows, combinando a potência de renderização do Chromium (via WebView2) com o visual clássico da moldura do Windows 7 Basic.

---

## Sobre o Projeto

O **Browsium** nasceu da ideia de criar um navegador autônomo, rápido e com personalidade única. Ele utiliza as tecnologias web mais modernas para garantir compatibilidade total com os sites atuais, ao mesmo tempo em que resgata a estética limpa e elegante das janelas clássicas do Windows através das APIs de DWM (Desktop Window Manager).

---

## Principais Recursos

- ⚡ **Motor Moderno (Chromium/WebView2):** Renderização rápida e compatibilidade total com páginas web atuais, sem depender de motores antigos como o Internet Explorer.
- 🖼️ **Estética Windows 7 Basic:** Moldura clássica com o tema azulado ativado nativamente via DWM.
- 🧭 **Navegação Completa:** Barra de endereços inteligente, botões de Voltar, Avançar, Atualizar e um menu suspenso de configurações.
- 📱 **Portátil e Direto:** Sem instaladores complexos; empacotado em um formato leve pronto para uso.

---

## 🛠️ Tecnologias Utilizadas

- **C# & Windows Forms (.NET Framework):** Construção da interface e controle da janela.
- **Microsoft Edge WebView2:** Motor de renderização web baseado em Chromium.
- **PowerShell & C++:** Automação e compilação dos scripts de inicialização.
- **DWM API (`dwmapi.dll`):** Forçamento da moldura clássica do Windows 7 Basic.

---

## 📦 Como Instalar e Usar

1. Baixe o pacote mais recente (`Browsium.zip`) na página de lançamentos (Releases).
2. Extraia o conteúdo para uma pasta de sua preferência.
3. Execute o script ou o inicializador correspondente para abrir o navegador.
