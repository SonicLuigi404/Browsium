Como iniciar o Browsium

1. Baixe o pacote Clique no botão acima para baixar o arquivo Browsium.zip para o seu computador.
2. Extraia os arquivos Clique com o botão direito em Browsium.zip e selecione "Extrair tudo" em uma pasta de sua preferência.
3. Abra o navegador Execute o inicializador ou o script Browsium.ps1 dentro da pasta extraída para abrir o navegador.
